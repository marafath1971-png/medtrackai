# Design skills for MedAI

Adapted from [emilkowalski/skills](https://github.com/emilkowalski/skills) (Emil Kowalski — Vercel/Linear design engineering).

| Skill | Use when |
| --- | --- |
| `medai-flutter-design` | Building or reviewing **this app's** Flutter UI |
| `emil-design-eng` | Core animation & polish philosophy |
| `apple-design` | Gestures, springs, materials, typography |
| `review-animations` | Strict motion code review |
| `animation-vocabulary` | Naming a motion effect |

Install updates from upstream:

```bash
npx skills@latest add emilkowalski/skills
```

Then copy new skills into `.cursor/skills/` if needed.
