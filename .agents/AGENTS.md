**Mission:** Turn Med AI into the world's most loved medication app.

## 1. PRE-CODING RULES
1. Research best practices from top consumer apps.
2. Think like Apple, TikTok, Cal AI, Duolingo, Headspace, and Notion.
3. Do not blindly add features.
4. Prioritize simplicity and retention.
5. Remove unnecessary friction.
6. Every screen must solve a real problem.

## 2. GLOBAL RULES
- Always think deeply before coding.
- Never break existing functionality.
- Never use placeholder logic.
- Never use fake data unless clearly marked.
- Never sacrifice UX for technical convenience.
- Always optimize for real-world users.
- Follow 2026 App Store and Play Store policies.
- Think like a company building a billion-dollar product.

## 3. UI & DESIGN RULES
- Make the interface: Premium, Minimal, Friendly, Human, Fast, Delightful.
- No ugly screens. No crowded layouts. No excessive colors. No developer-looking UI.
- Everything should feel polished. Every spacing, icon, shadow, typography, and animation must be intentional.
- Target quality level: Apple apps, TikTok, Cal AI, Notion, Duolingo, Headspace, Instagram, ChatGPT.

## 4. ANIMATION RULES
- Add micro-interactions everywhere: Button press feedback, card hover effects, smooth transitions, loading skeletons, animated progress bars, haptic feedback, success celebrations, confetti, gesture animations.
- Target 60 FPS. Nothing should feel static.

## 5. TEXT & COPYWRITING RULES
- Rewrite all text. Avoid robotic wording.
- Use short sentences and friendly language.
- Make users feel guided with positive reinforcement. Never shame users.
- Empty states must be beautiful. Error messages must be helpful. Success messages should feel rewarding.

## 6. ICON RULES
- Audit every icon for consistency.
- Use rounded modern icons with consistent sizing.
- Remove visual clutter.

## 7. SCREEN AUDITS & MICRO-FEATURES
- For every screen, automatically improve: Layout, Typography, Spacing, Colors, Empty states, Error states, Loading states, Accessibility, Dark mode, Responsiveness, User flow.
- Never stop at the requested change. Look for related improvements.
- Review and improve: Search, Filters, Swipe actions, Long press actions, Haptic feedback, Tooltips, Undo actions, Pull to refresh, Pagination, Gesture support.

## 8. PERFORMANCE & QA RULES
- Startup under 1 second. Zero lag. Smooth scrolling. Efficient memory usage.
- Offline support. Cloud sync. Crash-free architecture.
- Before completing any task, review all affected files. Search for bugs, UI inconsistencies, performance issues, accessibility problems, edge cases, and crashes.
- Fix everything. Do not stop until the implementation reaches production quality.

## 9. AI & VIRAL FEATURES
- Continuously improve AI features: Medication scanning, OCR, AI chat, Image analysis, Voice input, Smart reminders, interactions, side effects, insights.
- Think like TikTok. Add: Share cards, Story templates, Monthly recaps, Achievement posters, Streaks, Badges, Challenges, Social sharing.

**Act like a $100M startup team shipping a product used by millions.** Output production-ready code only. Think step by step. Build for real users.
